# Proxmox Homelab

My personal homelab built with Proxmox VE on a Dell OptiPlex.

## Hardware

- Dell OptiPlex 3020 MT
- Intel Core i5-4590
- 8 GB DDR3 RAM
- 120 GB SSD
- 500 GB HDD

## Virtualization

- Proxmox VE
- LXC containers
- Virtual Machines

## Services

- Jellyfin
- Samba
- Sonarr
- Radarr
- Prowlarr
- Bazarr
- Seerr
- Kavita
- Docker

## Networking

- Linux networking
- Virtual bridges
- Static IPs
- Tailscale

## What I Learned

- Linux system administration
- Virtualization with Proxmox
- Network configuration
- Storage management
- Docker and containers
- Service deployment
- Troubleshooting
